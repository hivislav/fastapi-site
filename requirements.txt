# --- RAG (базы знаний проекта, кнопка «RAG»): НЕобязательные зависимости ---
# Проект работает и без них: индексация уходит на встроенный офлайн-бэкенд
# эмбеддингов (stdlib, без сети), а PDF отвечает понятной причиной отказа.
# Ставятся отдельно и по желанию:
#
#   pip install pypdf                  # чтение PDF (текстовый слой)
#   pip install sentence-transformers  # семантические эмбеддинги (тянет torch)
#
# ВАЖНО про Python 3.9 (версия venv проекта): свежие sentence-transformers
# требуют 3.10+, поэтому ставятся пинованные версии:
#
#   pip install "numpy<2" "torch==2.2.2" "sentence-transformers==4.1.0"
#
# Модель скачивается один раз в RAG_MODEL_CACHE (data/rag/models) и дальше
# работает без сети. Подробности — в app/ai/rag_embedding.py и .env.example.
#
# Распознавание сканов (OCR) НЕ требует ни brew, ни pip: используется встроенный
# в macOS Vision, а хелпер (tools/vision_ocr.swift) собирается один раз через уже
# установленный swiftc в data/ocr/bin. На других системах распознавания нет —
# скан тогда отклоняется с объяснением.
#
# numpy отдельно ставить НЕ нужно, но он полезен и сам по себе: им считается
# близость при поиске по базе (с ним 5 000 чанков ищутся за 4 мс, без него —
# перебором на Python за 1,2 с). Приходит вместе с torch/sentence-transformers.
